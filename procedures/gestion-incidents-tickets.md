## 2) Exemple pédagogique (début de séance) : Ticket "mauvais" vs "bon"

### Ticket "mauvais"

- Problème : "Pronote marche pas."
- Symptômes : "Ça bug."
- Preuve : aucune
- Priorité : ?

### Ticket "bon"

- Problème (1 phrase) : "Impossible de se connecter à Pronote sur le poste PC-12 en salle B203 depuis 10h05."
- Symptômes : "Message : 'Trop de tentatives, réessayez plus tard'."
- Type : Incident ; Catégorie : Compte ; Service : Pronote
- Impact : 2 ; Urgence : 2 → Priorité 4/9
- Preuve : capture écran + navigateur + heure + message exact

## 3) Grille Impact / Urgence

### IMPACT (conséquence)

- 1 : gêne faible, on peut continuer autrement (ex : son HS)
- 2 : bloque une personne / une tâche (ex : impossible de se connecter)
- 3 : bloque plusieurs personnes OU sécurité/données (phishing, fuite, panne collective)

### URGENCE (délai)

- 1 : peut attendre
- 2 : aujourd'hui
- 3 : immédiat (cyber, propagation, données, collectif)

**Priorité = Impact × Urgence** (sur 9)

- 1–2 faible ; 3–4 moyen ; 6–9 haut (souvent escalade)

## 4) Fiche élève (1 page) — questions + méthode

Objectif : écrire un ticket compréhensible par un autre technicien.

### 4 infos obligatoires

- Qui ? Où ? Quand ? Quoi ?

### 8 questions du technicien

1. Explique en 1 phrase
2. Depuis quand ?
3. Poste + salle ?
4. Message exact ?
5. Contexte juste avant ?
6. D'autres ont le même souci ?
7. Ça bloque le travail ?
8. Risque cyber ? (clic, mot de passe donné, fichier, clé USB…)

### Preuves (min. 1) — règle simple

**Une preuve = un élément vérifiable.**

Format minimum attendu (au choix) :

- Capture écran + heure
- OU Message exact (copié) + application + heure
- OU URL / expéditeur + heure
- OU Nom du fichier + emplacement (dossier/ENT/Drive) + heure

---

## 5) Fiche prof — critères + attendus

Critères de réussite :

1. Qui/Où/Quand présents
2. Phrase problème claire
3. Catégorie correcte
4. Service / Application renseigné
5. Impact+Urgence+Priorité + justification
6. ≥ 1 preuve exploitable
7. Ticket exploitable (actions + test)

### Règle simple (escalade)

- **Si Catégorie = Cyber → Escalade OUI (systématique)**, même si le ticket n'est pas encore "résolu".

Escalade OUI si (exemples) :

- identifiants saisis sur lien
- compte compromis/usurpation
- partage public de données perso
- incident collectif
- message suspect sérieux

## 6) 16 cartes incidents (ENT/Pronote/Google) — 3 indices + preuve attendue (RECTO)

### Légende des niveaux

- **N1 (niveau 1) : incident simple** → objectif : écrire un ticket clair (Qui/Où/Quand/Quoi) + 1 preuve + 1 test simple.
- **N2 (niveau 2) : diagnostic** → objectif : faire au moins 1 test comparatif (autre poste / autre navigateur / navigation privée / autre compte) et noter le résultat.
- **N3 (niveau 3) : cyber / données / incident collectif** → objectif : sécuriser (ne pas aggraver) + recueillir des preuves + escalader immédiatement.

## 9) Main courante Excel (structure + automatisations)

### En-têtes (ligne 1)

| Colonne | En-tête |
|---|---|
| A | N° ticket |
| B | Date/heure |
| C | Demandeur |
| D | Salle |
| E | Poste |
| F | Technicien |
| G | Type |
| H | Catégorie |
| I | Service |
| J | Résumé |
| K | Preuve notée |
| L | Preuve auto |
| M | Impact |
| N | Urgence |
| O | Priorité auto |
| P | Escalade élève |
| Q | Escalade auto |
| R | À qui ? |
| S | Statut |
| T | Date clôture |
| U | Contrôle prof |
| V | Remarques prof |

### Formules (ligne 2, Excel FR)

**A2** (numéro automatique) :

```
="T"&TEXTE(LIGNE()-1;"000")
```

**L2** — Preuve auto (vérifie si la preuve notée en K2 contient au moins 10 caractères) :

```
=SI(NBCAR(K2)<10;"non";"oui")
```

**O2** — Priorité auto :

```
=SI(OU(M2="";N2="");"";M2*N2)
```

**Q2** — Escalade auto (Catégorie en H2, Priorité en O2) :

```
=SI(H2="Cyber";"oui";SI(O2="";"";SI(O2=9;"oui";"non")))
```

### Listes déroulantes

- **Demandeur / Technicien** : liste élèves (15)
- **Type** : Incident / Demande
- **Catégorie** : Cyber / Compte / Logiciel / Matériel / Réseau / Autre
- **Service** : ENT / Pronote / Office (Word/Excel/PPT) / Google / Réseau/Internet / Autre
- **Statut** : Ouvert / En cours / Résolu / Escaladé
- **Impact / Urgence** : 1 / 2 / 3
- **Escalade** : oui / non
- **À qui** : Référent numérique / Admin ENT-Pronote / Prof / Vie scolaire
- **Contrôle prof** : OK / À corriger

### Mise en forme conditionnelle

- Priorité ≥ 6 : orange ; = 9 : rouge
- Preuve auto = non : rouge clair
- Service vide : rouge clair
- Désaccord : si Escalade élève = non et Escalade auto = oui → rouge
